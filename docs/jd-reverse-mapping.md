## 2. SK하이닉스

- **결정적 사실**: 신입 IT 직무기술서 모집전공에 **"전산, 컴퓨터, 산업공학, 경영정보학, 전기, 전자, 반도체"** 명시 → 경영정보학과는 정공법 지원 가능.
- **신입 진입 직무**: IT-SW/시스템 개발(★최우선), IT-Infra. 나머지(MES·수율분석·AI/빅데이터·SCM·정보보안)는 대부분 **경력직(3~8년)**, 일부는 SK AX·쉴더스·intellix가 "하이닉스 근무" 형태로 채용.
- **전형**: 자소서(끈기/아이디어/전문성/팀워크 4항목) → SKCT(IT직무는 **코딩테스트로 대체, C/C++만, 2시간 4문제**) + A!SK(AI 화상면접, 25하 신규) → 면접 1회(서류 커트라인 높음).
- **요구 스택**: C/C++(코테), Java/Spring/React/SQL/Redis, 클라우드(AWS/Azure), MSA/Docker/K8s. 경영정보 차별화: SCM(CPIM), 정보보안 거버넌스(ISMS-P·정보보안기사), 데이터분석(통계+SQL+Python).
- **2026 상반기 신입 일정**: 서류 3/10~3/23 → SKCT+A!SK 4월 → 면접 5월 → 합격 6월 → 입사 7~8월.

## 3. NVIDIA

- **성격 차이**: 팹리스+플랫폼 SW 회사. 무게중심이 SW/AI. 한국 법인 공고는 **거의 경력직 Solutions Architect(3~5년+)**. 신입(NCG)·인턴 트랙은 대부분 글로벌 거점(미국/인도/대만).
- **CS/MIS 진입로**:
  - SW Engineer NCG(★★★★★ CS): C/C++/Python, 자료구조·OS·병렬컴퓨팅. 학사 충분(글로벌).
  - Data Scientist/Analyst/Engineer(★★★★ 양쪽, MIS 현실적): Python+SQL+BI, 단 다수 7년+ 경력.
  - IT/Infra/DevOps NCG(★★★★★ CS): 실제 NCG 2026 오픈 → SA보다 신입 가능성 높음.
  - Solutions Architect(한국 활발, 신입 벽 높음): 석/박사 선호, 한영 발표력.
  - TME/PM: 경력 요건 높음.
- **전형**: 리크루터 스크린 → 온라인 코딩(HackerRank/Codility) → 기술 폰스크린 → 온사이트 4~6라운드(알고리즘+**시스템 디자인+GPU/OS 아키텍처**+행동) → 오퍼. 핵심 시그널: 알고리즘 암기가 아니라 **코드가 하드웨어/메모리와 어떻게 상호작용하는지 설명하는 능력**.
- **한국 현실**: 영문 이력서+영어 면접 필수(단 영어 실력보다 기술·문제해결 우선). **referral이 사실상 필수**(대량지원 거절률 ~80%). 신입은 글로벌 NCG/인턴 + 인프라/데이터 직무로 우회가 현실적.

## 교차 인사이트 (3사 종합)

1. **"증명"의 형태가 회사마다 다르다**: 삼성=직무기술서 4번 자소서+창의성면접, 하이닉스=C/C++ 코테+1회 면접, 엔비디아=시스템 디자인+영어 프로젝트 설명+referral.
2. **공통 핵심 역량**: Python/SQL 데이터분석, C/C++ 코딩, 클라우드/인프라 이해. → 포트폴리오의 공통 뼈대.
3. **경영정보 전공자의 정공법 경로**: 하이닉스 IT(전공 명시) > 삼성 AI/IT인프라·SCM > 엔비디아 데이터 직무.
4. **전산/CS 전공자의 정공법 경로**: 3사 모두 코딩테스트/SW 트랙이 가장 직접적.

6. **도메인 지식 격차**: 반도체 공정·수율·MES 개념을 자신의 IT 역량과 연결해 설명하는 것이 합격 변별 요소(3사 공통).
