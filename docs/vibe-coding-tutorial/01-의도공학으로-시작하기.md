# 챕터 1: 의도공학으로 시작하기

> **소요**: 약 10분 (대화형 인터뷰)
> **핵심 인사이트**: 막연한 "취업 준비하고 싶다"를 코드처럼 다룰 수 있는 **의도 문서(INTENT.md)**로 바꾼다. 의도는 한 번에 완성하는 게 아니라 탐구로 수렴시킨다.

## Context
대부분의 사람은 "반도체 회사 취업 준비"라는 막연한 목표에서 바로 "자격증 뭐 따지? 자소서 어떻게 쓰지?"로 점프한다. 그러면 방향이 산으로 간다. 의도공학은 **What(무엇)·Why(왜)·Not(안 할 것)**을 먼저 정리해 흔들리지 않는 축을 만든다.

## The Prompt
```
경영정보나 전산학과를 졸업했거나 재학중인 학생이 삼성전자나 하이닉스같은
반도체 업체에 취업하기 위해서 준비하려고해. 의도공학을 사용해서 이 프로젝트를
시작하기 위한 심층인터뷰를 시작해줘.
```

## What Happened
AI는 곧바로 답을 쏟아내지 않고 **심층인터뷰**를 시작했다. 객관식 질문으로 한 단계씩 의도를 좁혔다:

1. **시작 상태 판별** — seed(씨앗) / exploring(탐구중) / clarified(명확함) 중 선택 → **seed** 선택
2. **의도의 주인** — 본인 / 학생들 / 일반화 → **학생들**
3. **핵심 문제** — 직무 매칭 모호함, 도메인 지식 격차, 전공 강점 연결 실패, 채용 정보 부족 (4개 모두 선택)
4. **가설** — 여기서 사용자가 중요한 걸 덧붙였다: *"AI를 활용해서 지식·포트폴리오를 최적화. 대상은 엔비디아·삼성·하이닉스. 신입뿐 아니라 경력·연구직도. **지원자가 그 일을 할 수 있음을 증명하면 취업 기회가 열린다**가 핵심 전제"*
5. **Not(경계)** — 허위/과장 포트폴리오 금지, 적성검사 대리·편법 금지, 특정 공정·언어 고정 안 함

이걸로 `INTENT.md`(status: seed)와 `CLAUDE.md`(Intent Constraints)가 생성됐다.

## The Result
```
INTENT.md
> status: seed
## Why   문제·가설·확인방법
## What  (비어있음 — 탐구하며 채움)
## Not   허위 금지·부정행위 금지·고정 금지
```
`CLAUDE.md`에는 Not이 **작업 규칙(Intent Constraints)**으로 박혀서, 이후 모든 작업이 자동으로 이 윤리 경계를 지키게 됐다.

## Lessons Learned
- **AI에게 "답"을 묻지 말고 "인터뷰"를 시키면** 내 생각이 정리된다. 객관식 질문이 막연함을 구체화한다.
- **가설은 틀려도 된다(seed)**. "증명하면 취업된다"는 전제는 나중에 사례로 검증된다(챕터 3).
- **Not을 먼저 정하면** 프로젝트가 윤리적으로·방향적으로 흔들리지 않는다. 여기서 정한 "허위 포트폴리오 금지"가 끝까지 모든 산출물의 가드레일이 됐다.

## Try It Yourself
여러분의 상황으로 바꿔서 시작해 보세요:
```
나는 [전공]을 [졸업/재학]했고 [목표 기업/직무]에 취업하고 싶어.
의도공학으로 내 취업 준비의 Why/What/Not을 정리하는 심층인터뷰를 해줘.
지금은 막연한 단계(seed)라서 Why부터 같이 채우고 싶어.
```
