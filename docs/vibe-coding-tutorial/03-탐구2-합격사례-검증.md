# 챕터 3: 탐구 2 — 합격사례로 가설 검증하기

> **소요**: 약 10분 (2개 에이전트 동시)
> **리서치 투입**: 병렬 에이전트 2기
> **핵심 인사이트**: 가설("증명하면 취업된다")을 믿지 말고 **실제 합격 사례로 검증**한다. 검증 결과 가설은 **조건부 참**이었다.

## Context
seed 단계에서 세운 핵심 전제 — "지원자가 포트폴리오로 '그 일을 할 수 있음'을 증명하면 전공 무관하게 취업 기회가 열린다" — 가 진짜인지 확인할 차례. 믿고 싶은 가설일수록 검증이 필요하다.

## The Prompt
```
전공에 상관없이 포트폴리오를 중심으로 반도체 기업에 취업한 사례가 있는지를
해외사례 포함해서 퍼플렉시티로 조사해
```

## What Happened
AI는 **국내 / 해외 2개 에이전트**를 동시에 띄웠다.
- 국내 에이전트: 비전공·문과 출신이 SSAFY·부트캠프 포트폴리오로 삼성·SK에 합격한 실명 사례 추적
- 해외 에이전트: NVIDIA·Intel·TSMC 등에서 비전공자가 포트폴리오로 합격한 사례 추적

## The Result — 가설 판정: **조건부 참 ✅**
검증된 실명 사례:
- 🇰🇷 초등교사 → 삼성 SW, 퇴사자 → SK하이닉스 데이터분석 (**자소서에 부트캠프 최종프로젝트 직접 기술**)
- 🌍 Titericz·Deotte·Tunguz → NVIDIA. **NVIDIA가 Kaggle 성과를 KGMON 팀으로 제도화**

하지만 **3가지 단서**가 붙었다:
1. **직무 한정** — SW·데이터·ML·IT만 성립. R&D/칩설계는 전공 장벽 견고.
2. **포트폴리오의 질** — 막연한 GitHub ❌ / **위조 불가능한(hard-to-fake) 성과물**만 작동.
3. **단독 불가** — 교육과정+코테+인적성 관문을 함께 통과해야.

## Lessons Learned
- **내가 세운 가설을 AI에게 "검증"시켜라.** 그냥 "맞아요"가 아니라 실명 사례·반례·한계까지 가져온다.
- 이 검증으로 INTENT.md의 Not("허위 포트폴리오 금지")이 **윤리를 넘어 실증적으로도 정당**해졌다 — 위조 가능한 포트폴리오는 실제로 안 통한다.
- 가설이 "조건부 참"으로 바뀌면서 타깃 직무가 **SW/데이터/ML/IT로 좁혀졌다**. 이게 의도가 수렴하는 과정이다.

## Try It Yourself
```
[내 전공/배경]과 비슷한 사람이 [목표 기업]에 포트폴리오로 취업한 실제 사례를
국내·해외 포함해 조사해줘. 실명/출처가 있는 사례만, 반례와 한계도 솔직히.
```
