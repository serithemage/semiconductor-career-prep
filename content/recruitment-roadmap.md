# 반도체 취업 준비 로드맵 타임라인

> 경영정보/전산 전공자가 삼성DS·SK하이닉스·NVIDIA의 SW·데이터·IT 직무를 노릴 때, **무엇을 언제 준비할지**를 시기별·기업별로 정리.
> 근거: [jd-reverse-mapping.md](../docs/jd-reverse-mapping.md), [portfolio-hire-cases.md](../docs/portfolio-hire-cases.md)
> ⚠️ 일정은 연도마다 바뀐다. 지원 시점에 각 사 채용 페이지에서 반드시 재확인.

---

## A. 기업별 전형 한눈에 비교
| | 삼성전자 DS | SK하이닉스 | NVIDIA |
|---|---|---|---|
| 채용 방식 | 정기 공채(연 2회, 상·하반기) | 정기 공모 + 상시 경력 | 상시·수시(글로벌 NCG/인턴) |
| 인적성 | **GSAT**(수리·추리) / SW직군은 **SW역량테스트** | **SKCT** / IT직군은 **코딩테스트(C/C++)** + A!SK | 온라인 코딩(HackerRank/Codility) |
| 면접 | 임원+직무+**창의성**(원데이) | 직무+인성(1회, 커트라인 높음) | 4~6라운드(알고리즘+**시스템디자인**+행동) |
| 공통 게이트 | **영어회화(OPIc/TOEIC Speaking) 필수**, 자소서 4번(직무 전문지식) | 자소서 4항목, 어학 필수 아님 | **영문 이력서+영어 면접, referral 사실상 필수** |
| 코테 언어 | C/C++/Java/Python | **C/C++만** | C/C++/Python |

> 참고 일정(예시, 2026 상반기 SK하이닉스): 서류 3/10~3/23 → SKCT+A!SK 4월 → 면접 5월 → 합격 6월 → 입사 7~8월.

## B. 시기별 준비 타임라인 (지원 D-day 기준 역산)

### D-12개월 ~ D-9개월 — 기반 다지기
- [ ] **방향 결정**: 직무 1~2개 선택(JD 역매핑 참고) → 본인 전공 강점과 연결
- [ ] **코딩 기본기**: 목표 회사 코테 언어로 알고리즘 시작 (삼성/SK는 C/C++ 권장)
- [ ] **도메인 학습 시작**: [domain-knowledge.md](domain-knowledge.md) 모듈 0~2
- [ ] **영어회화 착수**(삼성 지원 시 필수): OPIc/TOEIC Speaking 목표 설정

### D-9개월 ~ D-5개월 — 포트폴리오 빌드
- [ ] **JD 갭분석** 실행([jd-gap-analysis.md](templates/jd-gap-analysis.md)) → 갭 우선순위 도출
- [ ] **hard-to-fake 포트폴리오 1~2건** 제작([portfolio-samples/](portfolio-samples/) 참고): 실데이터+배포+협업+정량성과
- [ ] **자격증**(아래 C 참고): 데이터 직무면 빅데이터분석기사/ADsP, 보안/MIS면 정보보안기사·ISMS-P, SCM면 CPIM
- [ ] 도메인 모듈 3~5 + [domain-quiz.md](domain-quiz.md)로 자가진단

### D-5개월 ~ D-2개월 — 전형 대비
- [ ] **코테/SW역량테스트 집중**: 기출 유형, 시간 제한 모의(삼성 240분 2문제 / SK 2시간 4문제)
- [ ] **인적성**(GSAT/SKCT) 모의고사
- [ ] **영어회화 시험 응시**(삼성: OPIc IL↑ / TOEIC Speaking 110↑ 확보)
- [ ] (NVIDIA) **영문 이력서 + referral 네트워킹** 시작, 글로벌 NCG 공고 모니터링

### D-2개월 ~ D-day — 서류·면접
- [ ] **자소서 작성**: 직무기술서 기반, STAR + Issue→RootCause→Hypothesis→Test→Result 프레임. AI는 refine만(대필❌)
- [ ] **면접 대비**: 직무면접(전공·프로젝트 심층), 창의성/PT(삼성), 시스템디자인(NVIDIA)
- [ ] 포트폴리오 30초 데모 + 예상 후속질문 방어 준비

### D-day 이후
- [ ] 면접 복기 → 다음 라운드/다음 시즌 개선점 기록 (AI로 복기 보조 OK)

## C. 자격증 우선순위 (직무별)
| 직무 방향 | 1순위 | 2순위 | 비고 |
|---|---|---|---|
| 데이터/ML | 빅데이터분석기사, ADsP/ADP | SQLD | 삼성 DX·데이터 직무 사실상 표준 |
| 정보보안/MIS | 정보보안기사, ISMS-P 심사원 | ISO27001, PIA | SK 보안·거버넌스 트랙 |
| SCM/생산관리 | CPIM | — | 산업공학·물류 우대 |
| SW 공통 | 정보처리기사 | CSTS/ISTQB | 삼성 SW개발 우대 |
| 영어(삼성 필수) | OPIc / TOEIC Speaking | — | **자격증 아닌 필수 게이트** |

> 자격증은 "있으면 가점"이지 합격을 보장하지 않는다. **hard-to-fake 포트폴리오 > 자격증 나열**. 자격증은 갭분석에서 미커버 역량을 메우는 보조로 활용.

## D. 직무별 추천 경로 요약
- **전산/CS**: 삼성 SW개발(SW역량테스트) 또는 SK IT-SW(C/C++ 코테) 1순위 → C/C++ 코테 + hard-to-fake SW 프로젝트
- **경영정보/MIS**: SK IT(전공 명시!) / 삼성 AI·IT인프라·SCM → DB·거버넌스·SQL·BI 강점 + 데이터 포트폴리오
- **글로벌 지향**: NVIDIA 데이터/인프라 → 검증가능 성과(Kaggle/OSS) + 영문 이력서 + referral

## 체크리스트 (로드맵을 제대로 따랐다면)
- [ ] 목표 직무 1~2개와 그 전형(코테 언어·인적성·면접 종류)을 안다
- [ ] D-day 역산으로 코테·영어·자격증·포트폴리오 일정을 잡았다
- [ ] hard-to-fake 포트폴리오를 자격증보다 우선했다
- [ ] 자소서·면접에서 포트폴리오를 직무와 직결시킬 준비가 됐다
