# JD ↔ 역량 갭분석 프롬프트 템플릿

> 채용공고(JD)와 본인 이력을 입력하면, **증명해야 할 역량 / 본인 역량 갭 / 메울 액션**을 뽑아주는 재사용 프롬프트.
> ChatGPT·Claude 등 어떤 LLM에도 붙여넣어 쓴다. 근거: [ai-workflow.md](../../docs/ai-workflow.md)
>
> ⚠️ 윤리 경계: 이 템플릿은 **갭을 진단하고 준비 전략을 세우는 용도**다. 없는 경험을 만들거나 면접에서 방어 못 할 키워드를 넣는 데 쓰지 않는다. (Not: 허위/과장 금지와 일관)

---

## 사용법
1. 아래 `STEP 1` 프롬프트에 **JD 전문**과 **본인 이력/이력서**를 채워 실행.
2. 결과를 확인하고 `STEP 2`, `STEP 3`을 순서대로 이어서 실행(같은 대화창).
3. 마지막 `STEP 3` 산출물(갭→액션)을 포트폴리오 설계([skhynix-yield-data-analysis.md](../portfolio-samples/skhynix-yield-data-analysis.md))의 입력으로 사용.

---

## STEP 1 — 진단 (역량 추출 + 커버리지 분류)

```
너는 반도체 기업 채용을 잘 아는 커리어 코치다. 아래 [채용공고]와 [내 이력]을 비교 분석하라.

규칙:
- 없는 경험을 절대 지어내지 마라.
- 내가 면접에서 방어할 수 없는 항목은 "검증 필요"로 표시하라.
- JD에 명시된 표현/명확한 동의어가 내 이력에 있을 때만 "커버됨"으로 판정하라.

작업:
1) [채용공고]에서 "지원자가 증명해야 할 핵심 역량/책임" 상위 10개를 추출하라.
2) 각 역량을 내 이력 대비 [강하게 커버 / 약하게 커버 / 미커버]로 분류하라.
3) 표로 출력: | 역량 | JD 근거 문구 | 내 판정 | 판정 이유 |

[채용공고]
<<여기에 JD 전문 붙여넣기>>

[내 이력]
<<전공, 학점, 프로젝트, 인턴, 자격증, 사용 기술스택을 사실대로>>
```

## STEP 2 — 스코어링 + ATS 키워드 정렬

```
방금 분석을 이어서 진행하라.

1) 위 10개 역량 각각에 대해:
   - JD 중요도(1~5, 공고에서 강조된 정도)
   - 내 숙련도(1~5, 연차·프로젝트 복잡도·오너십·정량 성과 근거로)
   - 갭 점수 = 중요도 - 숙련도 (높을수록 시급)
   표로 출력하고 갭 점수 내림차순 정렬.

2) JD에서 ATS가 스캔할 핵심 키워드 15~30개를 추출해 4분류:
   (1) 하드스킬 (2) 소프트스킬 (3) 자격증 (4) 도메인 용어
   각 키워드를 [이력에 있음 / 없음]으로 2열 표 출력.
   ※ '없음'이지만 내가 실제로 할 수 있는 것은 "추가 가능", 방어 못 할 것은 "검증 필요"로 구분.
```

## STEP 3 — 갭 → 액션 (포트폴리오/학습 처방)

```
이어서, 갭 점수가 높은 상위 3~5개 역량을 30~60일 안에 메울 구체적 액션을 제안하라.

각 액션마다:
- 무엇을 (프로젝트 / 오픈소스 기여 / 자격증 / 학습)
- hard-to-fake 신호가 되려면 어떤 형태여야 하는지(실데이터·배포·협업·정량성과)
- 예상 소요 기간
- 완료 시 자소서/면접에서 쓸 한 줄(STAR 형식 초안)

규칙: 막연한 토이프로젝트 금지. 반드시 "검증 가능한 산출물" 중심으로.
출력은 우선순위 순으로.
```

---

## 출력 활용 흐름
```
STEP1 (증명할 역량 + 갭)
   → STEP2 (시급도 정렬 + ATS 키워드)
      → STEP3 (갭 메울 액션 = 포트폴리오 입력)
         → 포트폴리오 설계 템플릿으로 연결
```

## 체크리스트 (이 템플릿을 제대로 썼다면)
- [ ] 증명해야 할 핵심 역량 10개를 JD 근거와 함께 뽑았다
- [ ] "변별력 낮은 역량 vs 합격 가르는 역량"을 갭 점수로 구분했다
- [ ] '검증 필요' 키워드를 무리하게 이력에 넣지 않았다
- [ ] 갭을 메울 액션이 모두 hard-to-fake 산출물 중심이다
